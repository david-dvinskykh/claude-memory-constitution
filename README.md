# Конституция памяти

Шаблон долговременной памяти для ИИ-агента: 16 связанных баз в Notion плюс
письменная инструкция, по которой агент ведёт эту память сам.

**Документация: https://david-dvinskykh.github.io/claude-memory-constitution/**

## Установка одной командой

Скажите агенту с подключённым Notion:

```
Прочитай https://david-dvinskykh.github.io/claude-memory-constitution/spec/install.txt и выполни целиком.
```

Он спросит только, где создать базу, и дальше сделает всё сам: создаст базы,
свяжет их, соберёт конституцию с реальными id, заведёт служебные страницы
и выдаст готовый бутлоадер для настроек агента.

## Автообновление

Повторяющаяся задача раз в неделю:

```
Прочитай https://david-dvinskykh.github.io/claude-memory-constitution/spec/update.txt и выполни целиком.
```

Регламент сравнит версии и применит разницу. Он не удаляет ничего и не трогает
ваши данные — только структуру и служебный текст.

## Что внутри

| Файл | Что это |
| --- | --- |
| `version.json` | Текущая версия шаблона, машиночитаемо |
| `docs/spec/schema.json` | Спецификация 16 баз: DDL, связи, формулы, роллапы |
| `docs/spec/constitution.txt` | Текст конституции памяти — то, что кладётся в Notion |
| `docs/spec/install.txt` | Инструкция установки для агента |
| `docs/spec/update.txt` | Регламент обновления для агента |
| `docs/spec/migrations.json` | Цепочка миграций между версиями |
| `docs/*.md` | Человеческая документация, публикуется через GitHub Pages |

## Чем это отличается от обычной памяти агента

- **Атомарность** — один факт, одна строка, одно проверяемое утверждение.
- **Два времени** — когда произошло и когда записано, плюс интервал валидности.
- **Доверие** — подтверждено / вероятно / предположение / опровергнуто.
- **Инвалидация вместо удаления** — противоречие закрывает старый факт датой,
  а не затирает его.
- **Обучение на правках** — агент сам записывает правила работы с вами.
- **Лестница полномочий** — реестр того, что делается без спроса; вверх
  двигает только владелец, вниз система опускает себя сама.

Подробно — в [архитектуре](https://david-dvinskykh.github.io/claude-memory-constitution/architecture.html).

## Обезличенность

В шаблоне нет ничьих персональных данных: ни имён, ни номеров, ни адресов,
ни стран. Списки значений общие, поля нейтральные. Ничего никуда
не отправляется — установщик читает файлы по HTTPS и пишет только в ваш Notion.

## Ограничения версии 1.0

Только Notion. Файловые хранилища, почта, мессенджеры, календари и задачи
не поддерживаются.
