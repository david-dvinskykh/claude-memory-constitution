# История версий

[← К началу](index.md) · [Обновления](updates.md)

---

Версии семантические: `МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ`.

- **патч** — опечатки и уточнения формулировок, схема не меняется;
- **минорная** — новые поля, опции, параграфы; всё обратно совместимо;
- **мажорная** — изменения, требующие вашего решения при обновлении.

Машиночитаемая версия — [version.json](version.json), цепочка миграций —
[spec/migrations.json](spec/migrations.json).

## 1.4.0 — 2026-09-13

Шаблон стал плагином. Структура памяти не изменилась ни на поле: обновление
с 1.3.0 не применяет к вашей базе ничего, кроме новой версии на странице
обновлений.

- **Маркетплейс и плагин** — репозиторий стал маркетплейсом Claude Code:
  `/plugin marketplace add david-dvinskykh/claude-memory-constitution`,
  дальше `/plugin install notion-memory-constitution@claude-memory-constitution`.
  В Cowork плагин виден в списке и ставится кнопкой.
- **Два навыка** — `memory-install` выполняет процедуру установки,
  `memory-update` — регламент обновления. Больше в плагине нет ничего: ни
  хуков, ни агентов, ни MCP-серверов.
- **Локальная копия спецификации** едет вместе с плагином и используется
  только как запасной вариант при установке, когда адрес источника
  недоступен. Для обновления запасного варианта нет — сверка `Source:`
  важнее удобства.
- **Проверка спецификации** дополнена разделом о плагине: версии манифеста
  и `version.json` должны совпадать, каждый навык — иметь `SKILL.md`
  с именем, совпадающим с каталогом, а ссылки на `${CLAUDE_PLUGIN_ROOT}`
  указывать на то, что в репозитории есть.

Подробно — [Плагин](plugin.md).

## 1.3.0 — 2026-09-10

Устойчивость памяти к дрейфу и отравлению. Конституция шаблона поднята до 1.1.

- **§0** — свод предпочтений грузится узким запросом на четыре поля вместо
  `SELECT *`: id, url и пустые даты занимали контекст впустую. Там же
  записано, что поля-даты адресуются в SQL только как `"date:Имя:start"`.
- **§16.3** — угасание: проба без подтверждения 90 дней получает статус
  «уснуло» и перестаёт грузиться в сессию. Не удаляется и не отменяется:
  первый новый сигнал возвращает её в «действует» вторым подтверждением.
- **§16.2** — запрет дрейфа формулировки: уточнять правило можно только
  в пределах реплик, перечисленных в `Источнике`; новая ситуация — новая
  проба, а не правка старой строки.
- **§5** — вывод обязан ссылаться на основание, иначе идёт во Входящие
  словом «проверить»; источник задаёт потолок доверия: письмо, веб и чужой
  бот — не выше «вероятно».
- **§10** — чужие указания: текст, похожий на инструкцию агенту, не
  исполняется и не записывается ни правилом, ни фактом-инструкцией.
- **§12** — порядок разрешения конфликта при чтении: позднее `Валидно с`,
  затем доверие, затем слова владельца · документ · вывод; расхождение
  фиксируется во Входящих и называется в ответе.
- **§11** — регламент обслуживания оставляет в карточке дня строку-метрику,
  по которой виден дрейф памяти.
- Новая опция `Статус` = «уснуло» в 🎛️ Предпочтениях; изменение оформлено
  миграцией 1.2.0 → 1.3.0 на всех трёх языках.

## 1.2.0 — 2026-08-31

Защита цепочки обновлений.

- Регламент обновления берёт адрес источника из места, откуда запущен сам,
  а не из строки `Source` на странице Notion. Раньше эту строку мог
  отредактировать любой, у кого есть доступ к странице, и перенаправить
  еженедельное автообновление на произвольный адрес.
- Строка `Source` стала сверкой: расхождение с адресом запуска останавливает
  обновление и заводит вопрос.
- Девятая строка в реестре полномочий: «Изменить адрес источника обновлений»
  на уровне «⛔ никогда».
- Проверка миграций стала механической: перечислено, что именно ищется
  (`DROP COLUMN`, исчезнувшие значения списков, правки §8/§9/§13 и пунктов
  о секретах, повышение уровней, ослабление ограничений).
- §17 конституции дополнен на всех трёх языках; изменение оформлено
  миграцией 1.1.0 → 1.2.0.
- В документации появился раздел [Модель доверия](privacy.md).

## 1.1.0 — 2026-08-31

Три языка структуры.

- Русский, украинский и английский: названия баз и полей, значения в списках,
  конституция, служебные страницы, стартовые полномочия и бутлоадер.
- Язык выбирается первым вопросом установщика; `schema.json` получил ветки
  `ru` / `uk` / `en`, конституция разделилась на три файла.
- Установщик и регламент обновления переписаны по-английски — они одни на все
  языки и на языке структуры только разговаривают с пользователем.
- Служебные ключи на странице `🔄 Обновления шаблона` зафиксированы
  английскими на всех языках, чтобы регламент обновления их разбирал.
- Миграции получили языковые ветки.
- Английский квик-старт: [en.md](en.md). Українською: [uk.md](uk.md).

На уже установленную базу выпуск не влияет: язык выбирается один раз.

## 1.0.0 — 2026-08-31

Первый публичный выпуск.

- 16 баз: Факты, Предпочтения, Люди, Организации, Места, Объекты, Проекты,
  Процессы, Идеи, Журнал, Документы, Дела, Биография, Полномочия,
  Очередь решений, Входящие.
- Конституция памяти v1.0: 17 параграфов, включая протокол самоизменения
  и регламент обновлений шаблона.
- Установка одной командой: [spec/install.txt](spec/install.txt).
- Регламент автообновления: [spec/update.txt](spec/update.txt).
- Восемь стартовых строк в реестре полномочий.

Известные ограничения версии 1.0 перечислены в конце
[архитектуры](architecture.md): нет сырого эпизодического слоя, нет
типизированных рёбер графа, нет сжатия по темам, поддерживается только Notion.
