# История версий

[← К началу](index.md) · [Обновления](updates.md)

---

Версии семантические: `МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ`.

- **патч** — опечатки и уточнения формулировок, схема не меняется;
- **минорная** — новые поля, опции, параграфы; всё обратно совместимо;
- **мажорная** — изменения, требующие вашего решения при обновлении.

Машиночитаемая версия — [version.json](version.json), цепочка миграций —
[spec/migrations.json](spec/migrations.json).

## 1.0.0 — 2026-08-31

Первый публичный выпуск.

- 16 баз: Факты, Предпочтения, Люди, Организации, Места, Объекты, Проекты,
  Процессы, Идеи, Журнал, Документы, Дела, Биография, Полномочия,
  Очередь решений, Входящие.
- Конституция памяти v1.0: 17 параграфов, включая протокол самоизменения
  и регламент обновлений шаблона.
- Установка одной командой: [spec/install.txt](spec/install.txt).
- Регламент автообновления: [spec/update.txt](spec/update.txt).
- Восемь стартовых строк в реестре полномочий.

Известные ограничения версии 1.0 перечислены в конце
[архитектуры](architecture.md): нет сырого эпизодического слоя, нет
типизированных рёбер графа, нет сжатия по темам, поддерживается только Notion.
