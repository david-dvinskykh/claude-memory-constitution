# Обновления

[← К началу](index.md) · [Установка](install.md) · [Настройка под себя](customize.md)

---

Шаблон развивается: появляются поля, уточняются формулировки, исправляются
ошибки. Чтобы получать это, не переустанавливая ничего, у шаблона есть
регламент обновления — [spec/update.txt](spec/update.txt).

## Включить автообновление

Заведите у агента повторяющуюся задачу — раз в неделю достаточно —
с единственной строкой:

```
Прочитай https://david-dvinskykh.github.io/claude-memory-constitution/spec/update.txt и выполни целиком.
```

Где это делается:

- **Claude** — «Задачи» (recurring tasks): создать задачу с этим текстом,
  расписание еженедельно.
- Любой клиент с планировщиком — то же самое: одно сообщение по расписанию.
- Нет планировщика — просто присылайте эту строку руками раз в месяц.
  Регламент рассчитан и на ручной запуск.

Если ничего не изменилось, агент **ничего вам не скажет**. Это осознанно:
еженедельное «обновлений нет» — шум. Он молча обновит дату последней проверки
на странице `🔄 Обновления шаблона`.

## Что делает регламент

1. Находит страницу `🔄 Обновления шаблона`, берёт с неё адрес источника
   и установленную версию.
2. Скачивает `version.json` и сравнивает версии как семантические.
3. Версия новее — скачивает `migrations.json` и выстраивает цепочку миграций
   от установленной версии к новой.
4. Читает каждую миграцию целиком **до** первого изменения.
5. Применяет изменения схемы, потом текста конституции, потом новые страницы.
6. Пишет результат в журнал обновлений и в историю изменений конституции.
7. Отчитывается одной строкой — только если что-то изменилось.

## Границы — почему это безопасно

Регламент запускается без человека, поэтому его полномочия описаны запретами,
а не разрешениями.

| Никогда | Почему |
| --- | --- |
| Не удаляет ничего: ни страниц, ни баз, ни строк, ни полей | `DROP COLUMN` не выполняется, даже если стоит в миграции |
| Не трогает ваши данные | Факты, люди, документы, дела, предпочтения, журнал — вне зоны обновления |
| Не меняет §8, §9, §13.2 конституции | Честность об инструментах, правила «когда спрашивать» и сам протокол правок |
| Не поднимает уровни в ⚖️ Полномочиях | Уровень вверх двигает только владелец |
| Не сужает списки значений | `ALTER COLUMN SET` применяется, только если новый набор опций содержит все прежние — иначе у вас могут быть строки с исчезнувшим значением |
| Не восстанавливает ваши правки | Параграф, который вы переписали, обновление не вернёт к исходному виду |

Нарушение любого из этих пунктов в миграции означает, что **обновление
не применяется целиком**: заводится вопрос в 📮 Очередь решений, и решаете вы.

## Что происходит с вашими правками

Регламент ищет в конституции точный старый фрагмент. Не нашёл — значит,
параграф правили вы. Тогда он не заменяет ничего, записывает расхождение
в «не применено» и заводит вопрос: переносить ли изменение вручную.

Так локальная настройка не откатывается молча, но и не теряется из виду.

## Формат миграций

`migrations.json` — массив записей вида:

```json
{
  "from": "1.0.0",
  "to": "1.1.0",
  "date": "2026-09-15",
  "summary": "Одной строкой: что изменилось и зачем",
  "schema": [
    { "on": "facts", "statements": ["ADD COLUMN \"Вес\" NUMBER"] }
  ],
  "constitution": [
    { "section": "§5", "old": "точный старый фрагмент", "new": "новый фрагмент" }
  ],
  "pages": [],
  "manual": ["Что владельцу придётся сделать руками, если такое есть"]
}
```

`from` и `to` образуют цепочку: обновление с 1.0.0 до 1.2.0 применяет
1.0.0 → 1.1.0, затем 1.1.0 → 1.2.0. Разрыв в цепочке — повод остановиться
и спросить, а не догадываться.

## Проверить версию вручную

Текущая версия шаблона всегда лежит по адресу
[version.json](version.json). Установленная у вас — на странице
`🔄 Обновления шаблона` в Notion.

## Как откатиться

Отката нет и не будет: обновление ничего не удаляет, поэтому и восстанавливать
нечего. Добавленное поле, которое вам не нужно, можно удалить руками в Notion —
на остальную структуру это не влияет. Изменённый параграф конституции —
вернуть по [истории изменений](install.md), она ведётся на подстранице
конституции.
