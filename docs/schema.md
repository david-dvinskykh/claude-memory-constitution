# Схема баз

[← К началу](index.md) · [Архитектура](architecture.md) · [Конституция](constitution.md)

---

Полная спецификация 16 баз: поля, типы, списки значений и связи. Машиночитаемая версия того же самого — [spec/schema.json](spec/schema.json); именно её читает установщик, эта страница сгенерирована из неё.

Обозначения: **св.** — связь с другой базой, **↩** — обратная сторона связи, созданная автоматически, **∑** — роллап или формула.
